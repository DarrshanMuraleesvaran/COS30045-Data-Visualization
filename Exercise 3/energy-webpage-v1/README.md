# Exercise 3 Energy Website

This folder contains the Exercise 3 version of the Energy View website.

## Pages

- `index.html` - homepage and calculator.
- `televisions.html` - TV energy factors.
- `storyboard.html` - data story and visualisation narrative.
- `about.html` - project context.

## Assets

- `css/styles.css`
- `js/scripts.js`
- `images/`
- `data/`

The website is used as the richer design base for later templates.
