# Exercise 5

Exercise 5 builds several D3 chart types using the energy webpage.

## Exercises

- `Exercise 5.1` - vertical bar chart with axes for average energy consumption by screen technology.
- `Exercise 5.2` - line chart using Australian electricity spot price data.
- `Exercise 5.3` - donut chart showing the proportion of TV models by screen-size category.

## Focus

- SVG chart containers
- D3 scales and axes
- CSV loading
- Bar, line, scatter, and donut chart construction
