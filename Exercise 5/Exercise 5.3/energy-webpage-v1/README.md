# Exercise 5.3 Energy Webpage

This webpage extends Exercise 5.2 with a donut chart.

## Visualisations

- Bar chart for mean TV energy consumption by screen technology.
- Line chart for average Australian electricity spot prices.
- Donut chart for the proportion of TV models by screen-size category.

## Main Files

- `index.html`
- `css/styles.css`
- `js/scripts.js`
- `js/line-chart.js`
- `js/donut-chart.js`
- `data/Data_exercise 5.3.csv`

Run through a local server so D3 can load the CSV files.
