# Exercise 5.2 Energy Webpage

This webpage extends Exercise 5.1 with a line chart.

## Visualisations

- Bar chart for mean TV energy consumption by screen technology.
- Line chart for average Australian electricity spot prices from 1998 to 2024.

## Main Files

- `index.html`
- `css/styles.css`
- `js/scripts.js`
- `js/line-chart.js`
- `data/ARE_Spot_Prices.csv`

Run through a local server so D3 can load the CSV files.
