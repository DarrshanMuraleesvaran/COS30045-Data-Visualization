# Exercise 6.2 Energy Webpage

This webpage extends Exercise 6.1 with interactive histogram filters.

## Visualisation

The histogram can be filtered by:

- screen technology: All, LED, LCD, OLED.
- selected screen sizes: All Sizes, 24, 32, 55, 65, 98 inches.

The bars update with D3 transitions when a filter is selected.

## Main Files

- `index.html`
- `css/visualisation.css`
- `js/load-data.js`
- `js/shared-constants.js`
- `js/interactions.js`
- `js/histogram.js`
- `data/W6_TVdata.csv`

Run through a local server so D3 can load the CSV file.
