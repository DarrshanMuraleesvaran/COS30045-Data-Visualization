# Exercise 6

Exercise 6 develops interactive D3 visualisations using the Week 6 TV dataset.

## Exercises

- `Exercise 6.1` - histogram of labelled annual energy consumption.
- `Exercise 6.2` - histogram filters by screen technology and selected screen sizes.
- `Exercise 6.3` - scatterplot of star rating against energy consumption, colour-coded by screen technology.
- `Exercise 6.4` - scatterplot tooltips showing TV screen size.

## Dataset

The exercises use `W6_TVdata.csv`, which includes:

- `brand`
- `model`
- `screenSize`
- `screenTech`
- `star`
- `energyConsumption`

Run each webpage through a local server so D3 can load the CSV file.
