ABOUT THE PROJECT

Turning television energy data into something people can understand.

This website was created as part of COS30045 Data Visualisation to explore how web development and data storytelling can work together.

THE PURPOSE

More than simply displaying a chart.

The project began as an introduction to HTML, CSS, JavaScript and GitHub before evolving into a data storytelling exercise.

The goal is to present television energy-consumption information in a way that is clear, visually engaging and understandable to a non-technical audience.

The website uses exploratory findings from a television dataset and develops them into simple questions that consumers can relate to.
