SVG Coordinate Examples

Annotated examples showing how SVG coordinates, dimensions and path instructions relate to the house and garden illustration.

Understanding SVG Coordinates

SVG elements are positioned inside their own coordinate system. In this exercise, the SVG uses a viewBox beginning at coordinate (0,0), which represents the top-left corner.

Coordinate direction

(0,0) = top-left corner
X values increase towards the right
Y values increase downwards
1

Rectangle, Circle and Ellipse

This example demonstrates how rectangles use x and y coordinates together with width and height. Circles use centre coordinates and a radius, while ellipses use centre coordinates together with horizontal and vertical radii.

2

Line, Polygon and Polyline

A line uses a starting coordinate and an ending coordinate. A polygon joins multiple points and automatically forms a closed shape. A polyline also connects multiple coordinate points, but does not automatically close the shape.

3

Path and Text

The path element uses drawing commands inside the d attribute. M defines the starting point, C creates a cubic Bézier curve and L creates a straight line. The text element uses x and y coordinates together with text-anchor to control its position.
