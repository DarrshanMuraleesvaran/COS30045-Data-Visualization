# COS30045 Data Visualisation

This repository contains the weekly exercises and website work for COS30045 Data Visualisation.

The project focuses on building web-based data visualisations with HTML, CSS, JavaScript, and D3.js. The main dataset used across later exercises is a television energy-consumption dataset, which is used to explore screen technology, screen size, star rating, and labelled annual energy consumption.

## Repository Structure

- `Exercise 0.2` - reusable base website template.
- `Exercise 3` - data story website pages for TV energy consumption.
- `Exercise 4` - introductory D3 and SVG exercises.
- `Exercise 5` - bar, line, scatter, and donut chart exercises.
- `Exercise 6` - interactive histogram, filters, scatterplot, and tooltip exercises.

## How To View A Webpage Exercise

For D3 exercises that load CSV files, run a local server from the relevant `energy-webpage-v1` folder. For example:

```bash
npx serve .
```

Then open the local URL shown in the terminal.
